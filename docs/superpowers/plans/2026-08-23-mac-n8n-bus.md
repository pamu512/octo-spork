# Mac n8n Bus Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Run self-hosted n8n on Anoop's Mac as a durable schedule/webhook bus that calls existing scripts and routes WhatsApp to Briefs vs Alerts chats—without moving judgment into n8n.

**Architecture:** Approach B from `docs/superpowers/specs/2026-08-23-mac-n8n-bus-design.md`. Mac n8n schedules and webhooks invoke thin bash wrappers around octo-spork / hermes-fraud-intel / hermes-finance-brief / `gh`. Success briefs go to WhatsApp Briefs; failures and CI red go to WhatsApp Alerts. Agents keep ship/defer/cut.

**Tech Stack:** n8n (Docker on Mac), bash wrappers, existing Python CLIs, Hermes WhatsApp gateway delivery (`whatsapp:+E164`), GitHub webhooks or `gh`, Ollama on localhost:11434, timezone `Asia/Hong_Kong`.

## Global Constraints

- Host is the Mac only for wave 1 (not Tarka compose n8n).
- Scripts stay the source of truth; n8n nodes do not reimplement RSS/clustering/audit logic.
- Never auto-merge, never launch cloud agents from n8n, never decide ship/defer/cut.
- WhatsApp: two destinations — Briefs vs Alerts (env `WA_BRIEFS_TO`, `WA_ALERTS_TO`).
- Fail closed: missing binary / non-zero exit / `.failed.md` → Alerts, never silent success.
- Green CI / green audit → no WhatsApp message.
- Repo for bus assets: `pamu512/octo-spork` under `deploy/n8n/` (already holds `octo_nightly_audit.workflow.json`).
- Do not commit secrets; use n8n credentials + Mac env file `deploy/n8n/.env.local` (gitignored).

- [ ] **Step 3: Implement `wa_send.sh`**

```bash
#!/usr/bin/env bash
# deploy/n8n/scripts/wa_send.sh
# Route a short message to WhatsApp Briefs or Alerts via Hermes deliver target.
set -euo pipefail

CHANNEL=""
TEXT=""
FILE=""

usage() {
  echo "Usage: wa_send.sh --channel briefs|alerts (--text MSG | --file PATH)" >&2
  exit 2
}

while [[ $# -gt 0 ]]; do
  case "$1" in
    --channel) CHANNEL="${2:-}"; shift 2 ;;
    --text) TEXT="${2:-}"; shift 2 ;;
    --file) FILE="${2:-}"; shift 2 ;;
    *) usage ;;
  esac
done

[[ -n "$CHANNEL" ]] || usage
[[ -n "$TEXT" || -n "$FILE" ]] || usage

case "$CHANNEL" in
  briefs) TO="${WA_BRIEFS_TO:?WA_BRIEFS_TO unset}" ;;
  alerts) TO="${WA_ALERTS_TO:?WA_ALERTS_TO unset}" ;;
  *) echo "unknown channel: $CHANNEL" >&2; exit 2 ;;
esac

if [[ -n "$FILE" ]]; then
  [[ -f "$FILE" ]] || { echo "missing file: $FILE" >&2; exit 1; }
  BODY="$(cat "$FILE")"
else
  BODY="$TEXT"
fi

# Prefer Hermes CLI send if present; fail closed otherwise.
if command -v hermes >/dev/null 2>&1; then
  # Exact subcommand may be `hermes send` / `hermes message` depending on Hermes version —
  # probe with `hermes --help` on the Mac and adjust one line here only.
  printf '%s\n' "$BODY" | hermes send --to "$TO" --stdin
  exit $?
fi

echo "hermes not on PATH; cannot deliver to $TO" >&2
exit 1
```

`run_hermes_brief.sh`:

```bash
#!/usr/bin/env bash
set -euo pipefail
KIND="${1:?usage: run_hermes_brief.sh fraud|finance}"
case "$KIND" in
  fraud) ROOT="${HERMES_FRAUD_ROOT:?}" ;;
  finance) ROOT="${HERMES_FINANCE_ROOT:?}" ;;
  *) echo "kind must be fraud|finance" >&2; exit 2 ;;
esac
cd "$ROOT"
python3 scripts/dump_recent.py --write-brief
DAY="$(date +%F)"
if [[ -f "briefs/${DAY}.md" ]]; then
  echo "OK briefs/${DAY}.md"
  exit 0
fi
if [[ -f "briefs/${DAY}.failed.md" ]]; then
  echo "FAIL briefs/${DAY}.failed.md"
  exit 1
fi
echo "FAIL no brief for ${DAY}" >&2
exit 1
```

`check_tarka_master_ci.sh`:

```bash
#!/usr/bin/env bash
set -euo pipefail
# Latest completed workflow run on master; fail if conclusion=failure
JSON="$(gh run list -R pamu512/tarka --branch master --limit 1 --json conclusion,url,name,displayTitle)"
echo "$JSON"
python3 - <<'PY' <<<"$JSON"
import json,sys
runs=json.load(sys.stdin)
if not runs:
    raise SystemExit(1)
c=(runs[0].get("conclusion") or "").lower()
print(runs[0].get("url") or "")
raise SystemExit(0 if c in {"success","neutral",""} else 1)
PY
```

Note: empty conclusion while in progress should exit 0 (no alert spam). Only `failure` / `timed_out` / `cancelled` → exit 1. Adjust the Python exit list accordingly:

```python
raise SystemExit(0 if c not in {"failure", "timed_out", "cancelled"} else 1)
```

1. Schedule Trigger — cron `30 7 * * *`, timezone Asia/Hong_Kong  
2. Execute Command — `bash /host/repos/.../octo-spork/deploy/n8n/scripts/run_hermes_brief.sh fraud`
